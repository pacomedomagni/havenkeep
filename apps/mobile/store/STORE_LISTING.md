### Description (4000 char max)
```
HavenKeep is a personal warranty manager for your home. Every appliance, electronic, and big-ticket purchase has a warranty hiding somewhere — and most of them expire unused. That's $16 billion left on the table every year.

HavenKeep keeps every warranty in one place, reminds you before they expire, and shows the savings stack up.

WHAT'S INSIDE

· Item Library — your fridge, dishwasher, HVAC, TV, lawn mower — every product with a warranty, in one organized list per home.

· Smart Receipt Scan — point the camera at a paper receipt or import an image, and HavenKeep extracts the product, store, price, and warranty terms automatically. Re-runs are free; the same scan never burns your daily quota twice.

· Email Receipt Import — connect Gmail or Outlook (read-only access, retailer senders only) and HavenKeep imports orders from Amazon, Best Buy, Home Depot, and more. Cancel mid-scan, disconnect any time, and review low-confidence matches before they're added.

· Warranty Reminders — push and email reminders before every warranty ends. Configurable: 60-day heads-up, 14-day final call, or your own schedule.

· Maintenance Schedules — HVAC filters, smoke-detector batteries, water-heater anode rods. Pre-loaded schedules per category, due-soon reminders, history log, and missed-maintenance flags that protect your warranty rights.

· Warranty Claims — file a claim, log the repair cost, and watch the savings tally grow. The dashboard shows total savings to date so the value is concrete.

· Warranty Marketplace — when an item's manufacturer warranty is about to expire on a high-value piece, HavenKeep surfaces an extended warranty offer so coverage doesn't lapse. Sales are vetted and priced transparently.

· Multi-home Support — manage your primary residence and rental properties separately, each with its own item list and home details.

· Document Vault — receipts, warranty cards, manuals. Encrypted at rest, offline-accessible, exportable.

· Partner Gifts — realtors and home builders can gift Premium to clients at closing. Shows up in your inbox with a redemption code.

PRIVACY-FIRST

· Encrypted local data — SQLCipher (AES-256) protects your library on-device, even if the phone is lost.
· No advertising, no third-party tracking, no data sales.
· Email-receipt scanning is read-only and limited to retailer senders. Disconnect anytime; we delete the OAuth tokens.
· One-tap account deletion + 30-day cooling-off recovery window.

HAVENKEEP PREMIUM

The free tier covers 5 items, full warranty tracking, reminders, maintenance schedules, claims logging, and document storage. Premium unlocks unlimited items, the email-receipt scanner, multi-home, the marketplace, and priority claim support.

NOT FINANCIAL ADVICE

HavenKeep tracks warranty terms supplied by manufacturers and retailers. We don't sell, underwrite, or service warranties — we surface what's already yours.
```

## App Store — App Privacy Questionnaire

### Data **Linked** to the user (collected and tied to identity)

| Data Type | Collected? | Linked to user? | Used for tracking? | Purpose |
|---|---|---|---|---|
| **Email Address** | Yes | Yes | No | App Functionality (account, sign-in, password reset, customer support) |
| **Name** | Yes | Yes | No | App Functionality (greeting, profile) |
| **Photos or Videos** | Yes | Yes | No | App Functionality (item photos, receipt + warranty card scans) |

| **Purchases** | Yes | Yes | No | App Functionality (Premium subscription state via RevenueCat) |
| **Customer Support** | Yes | Yes | No | App Functionality (in-app contact, deletion + export requests) |
| **User ID** (server-side UUID) | Yes | Yes | No | App Functionality (authentication, data scoping) |

### Data **NOT Linked** to the user

| Data Type | Collected? | Notes |
|---|---|---|
| **Crash Data** | Yes | Firebase Crashlytics — its install-id is not the user id |
| **Performance Data** | No | Not currently collected |

### Data **NOT** collected
- Phone Number
- Physical Address (homes have a *home* address but it's user-entered content, not a contact mechanism)
- Audio
- Browsing History
- Search History
- Contacts
- Location (precise or coarse — HavenKeep does NOT use any location API)
- Health/Fitness data
- Financial Info (subscription handled by Apple/Google + RevenueCat — HavenKeep never sees card data)
- Advertising Data
- Sensitive Info
- Third-party advertising identifiers (no IDFA, no ad networks)

### Tracking
**Does your app track users?** → **No.** HavenKeep does not link user data with third-party data for advertising and does not share data with data brokers. `NSPrivacyTracking=false` in the manifest.

## Google Play — Data Safety Form

Equivalent fields for the Play Console "Data safety" section:

### Data collected
- **Personal info → Email address** — Required, Collected, Encrypted in transit, User can request deletion
- **Personal info → Name** — Required, Collected, Encrypted in transit, User can request deletion
- **Personal info → User IDs** (server-side UUID) — Required, Collected, Encrypted in transit, User can request deletion
- **Photos and videos → Photos** (item + receipt + warranty card images) — Optional, Collected, Encrypted in transit, User can request deletion
- **App activity → In-app actions** (item entries, claim filings, maintenance logs) — Required, Collected, Encrypted in transit, User can request deletion
- **App info and performance → Crash logs** (Firebase Crashlytics) — Optional, Collected, Encrypted in transit
- **Financial info → Purchase history** (Premium subscription state only — never card numbers) — Required, Collected, Encrypted in transit
- **Messages → Emails (subject + sender + body)** — Optional, Collected, Encrypted in transit, **Processed but not retained** — only when the user connects Gmail / Outlook for receipt import. The body is sent to OpenAI for parsing, then discarded; only the extracted item is stored. User can disconnect any time and revoke access.

### Data shared with third parties
- **Subscription state shared with RevenueCat** for entitlement management (no card data passes through HavenKeep or RevenueCat — card data is handled by Apple/Google)
- **Push notification token shared with Firebase Cloud Messaging** (only after the user grants notification permission)
- **Receipt-image content shared with OpenAI** for OCR extraction during a scan or email import. Image bytes leave HavenKeep's servers, hit OpenAI's vision API, and the response (extracted item fields) is what's stored. OpenAI is configured for zero-data-retention; this is documented in our DPA.

### Security practices
- Data is encrypted in transit ✓ (TLS)
- Data is encrypted at rest ✓ (SQLCipher locally; encrypted disks server-side)
- Users can request data deletion ✓ (in-app one-tap, 30-day cooling-off, then permanent purge)
- Users can request a copy of their data ✓ (export endpoint)
- Independent security review: **No** (skip)
- Committed to Play's Families Policy: **No** (HavenKeep is rated for general audience but not designed for children under 13)
